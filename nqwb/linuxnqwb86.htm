念青五笔 for Linux · 86 版

念青五笔 Linux 版 1.0.0，和 Windows 版（3.1.0 r19，繁體版 3.1.0 T r1）用同一份打字引擎和同一份码表：候选顺序、逐键提示、联想、空码猜词、重码补词、zz 临时拼音、简繁输出、自造词、调整词序、自定义短语，打出来的结果和 Windows 上一样。

这一页是 86 版：包括 念青五笔（86 版五笔）和 念青五筆（86 版，繁體字碼表）。一个下载包里简体、繁体都有，安装时选一个装，也可以两个都装。98 版请看 念青五笔98版 for Linux。

不知道自己的 CPU？打开终端（按 Ctrl+Alt+T，或者点应用菜单、搜索“终端”打开），运行 uname -m：显示 x86_64 就是一般电脑（amd64），显示 aarch64 就是 ARM 电脑（arm64）。同一套包通用：Ubuntu 22.04、24.04、25.10、26.04 LTS、Debian 12、13 都能用，系统升级后也不用重装；.rpm 用于 Fedora 43、44。

安装（用安装脚本，最简单）

第一步：下载并解压。上面按你的系统和 CPU 下载一个包。下载好后，在文件管理器里对着压缩包点右键 → “解压缩到这里”。也可以在终端里解压（以 Ubuntu / Debian 一般电脑那个包为例）：

tar xf nqwb86-linux_v1.0.0_deb_amd64.tar.gz
ls

解压后会得到一个同名文件夹（去掉 .tar.gz，就是上面下载表里“解压后文件夹”那一行）。

第二步：进到解压出来的文件夹。

cd nqwb86-linux_v1.0.0_deb_amd64

其它三个包就把文件夹名换成你那个包对应的（见上面下载表）。

第三步：运行安装脚本。

./install.sh

它会问装哪个版本，直接回车就是第一个（念青五笔，简体）；想装繁體就选念青五筆，想两个都装就选“全部都装”。它自己认出是 Ubuntu / Debian（用 apt 装 .deb）还是 Fedora（用 dnf 装 .rpm）和 CPU，装的时候要输一次 sudo 密码：输入密码时屏幕上什么都不显示（连 * 都没有），这是正常的，输完按回车就行。

常用写法：

./install.sh --edition 86        # 只装念青五笔
./install.sh --edition 86 --edition 86t    # 简体、繁體两个都装
./install.sh --ibus               # 只装 IBus 版
./install.sh --fcitx5             # 只装 Fcitx5 版
./install.sh -y                   # 不问，直接装简体版

如果这个包和你的系统、CPU 对不上，脚本会直接告诉你该下载哪一个包，不会硬装。

第四步：让输入法生效。注销再登录一次，或者运行 ibus restart（IBus 用户），然后看下面“启用输入法”。

安装（自己用 apt / dnf 装，不用脚本也行）

Ubuntu / Debian（一般电脑），只装念青五笔：

sudo apt install ./deb/amd64/nqwb-common_*.deb ./deb/amd64/ibus-nqwb_*.deb ./deb/amd64/nqwb86_*.deb

用 Fcitx5 的把 ibus-nqwb 换成 fcitx5-nqwb；装繁體版把 nqwb86 换成 nqwb86t；ARM 电脑把 deb/amd64 换成 deb/arm64。Fedora（一般电脑）：

sudo dnf install ./rpm/x86_64/nqwb-common-*.rpm ./rpm/x86_64/ibus-nqwb-*.rpm ./rpm/x86_64/nqwb86-*.rpm

ARM 机器把 rpm/x86_64 换成 rpm/aarch64。

启用输入法（只做一次）

IBus（Ubuntu / Debian / Fedora 的 GNOME 桌面）

打开 设置 → 键盘 → 输入源，点 ＋，选 汉语（中国），再选 念青五笔，点“添加”。繁體版在 汉语（台湾） 下面：念青五筆。打字时按 Super（Windows 键）+ 空格 切换到念青五笔。

KDE、Xfce、MATE 等用 IBus 的桌面：运行 ibus-setup → 输入法 → 添加 → 汉语 → 念青五笔。系统里还没启用 IBus：Ubuntu / Debian 运行 im-config -n ibus 后注销再登录。设置里找不到念青五笔：先注销再登录；还不行运行 sudo ibus write-cache --system 再 ibus restart。

Fcitx5（Kubuntu / KDE、Deepin 等）

运行 fcitx5-configtool（或 系统设置 → 输入法）。右边取消勾选“仅显示当前语言”，搜索“念青”，把 念青五笔 移到左边。默认 Ctrl+空格 打开 / 关闭输入法。Ubuntu / Debian 想让 Fcitx5 当默认框架：运行 im-config -n fcitx5，注销再登录。

GNOME + Wayland 下用 Fcitx5，要先装 GNOME 扩展“Input Method Panel”（kimpanel），不然看不到候选窗。Fcitx5 的左 Shift：Fcitx5 自己默认用左 Shift“临时切换到第一个输入法”，所以 Fcitx5 里左 Shift 由 Fcitx5 处理，右 Shift 才由念青五笔切中/英。想让左 Shift 也交给念青五笔：在 Fcitx5 的“全局选项 → 临时在当前和第一个输入法之间切换”里把左 Shift 去掉。

状态栏和输入法名称

X11 桌面（Ubuntu 选“Ubuntu on Xorg”登录、Xfce、MATE、Cinnamon、KDE X11 等）：用念青五笔时屏幕左下角出现和 Windows 一样的浮动状态栏：

[青 中/英] [念青五笔] [● 全/半角] [。， 中/英标点] [简/繁] [▾]

点各个按钮切换；▾（或在状态栏上点右键）打开菜单：设置…、关于、状态栏回到左下角、隐藏状态栏。按住拖动可以挪位置，下次还在那里。切到别的输入法时状态栏自动隐藏。不想要：设置 → 外观 → 取消“显示状态栏”。配色可选 经典 / 简洁 / 可爱粉色 / 海洋蓝。

Wayland 桌面（Ubuntu 22.04 起、Fedora 的默认 GNOME 登录）：Wayland 不允许程序自己把窗口放在固定位置、一直在最上面，所以不显示浮动状态栏，改为在候选窗顶行编码前面显示“念青五笔”，不是默认状态时跟在名称后面，如“念青五笔·全角·英文标点·繁”（设置 → 外观 → “Wayland 下在候选窗显示名称”可以关掉）。中/英状态看屏幕右上角面板上的输入法图标，也可以在那里点菜单切换；切换用的快捷键和 X11 下一样。

只列出装了的版本。装了两个以上版本时，顶上“设置适用于”可以选“所有版本”或“只对 念青五笔”这样的单个版本。按“确定”或“应用”保存，输入法 2 秒内自动生效，不用重启。

全部设置、自造词都在 ~/.config/nqwb/：nqwb.conf（设置，每一项都有中文说明，键名就是 Windows 注册表里的值名）、Nqwb86.usr.txt（自造词）、Nqwb86.ord.txt（调整过的词序）、Nqwb86.phrase.txt（自定义短语）、Nqwb86.MB（可选，自己做的码表，放在这里就优先用它）、status.pos（状态栏位置）。从 Windows 搬过来：把 Windows 上 %APPDATA%\Microsoft\IME\念青五笔\ 里的 Nqwb86.usr.txt、Nqwb86.ord.txt、Nqwb86.phrase.txt 拷到 ~/.config/nqwb/；设置：在 Windows 上用 regedit 导出 HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\念青五笔，在设置窗口“词库”页点“导入 Windows 注册表设置…”选这个 .reg 文件（或终端运行 nqwb-import-reg 念青五笔.reg）。命令行工具：nqwb-cli -v khlg（终端里试打）、nqwb-cli -r 中国（编码反查）、nqwb-mbtotxt / nqwb-mbpack（码表 MB ↔ TXT）。

常见问题

  • 设置里找不到念青五笔：注销再登录；还不行运行 sudo ibus write-cache --system 后 ibus restart。
  • 候选窗不出来：确认当前框架真的是 IBus（echo $GTK_IM_MODULE 应为 ibus）或 Fcitx5（fcitx）。
  • 状态栏不出来：Wayland 下本来就不显示（看候选窗顶行的名称）；X11 下看设置 → 外观 → 显示状态栏。
  • 候选顺序乱了：念青五笔有名称校验（同 Windows），不要改 /usr/share/ibus/component/nqwb86.xml、/usr/share/fcitx5/inputmethod/nqwb86.conf 里的输入法名称；改了就重新安装那个版本的包。
  • Flatpak / Snap 程序：IBus 通过门户（portal）工作，一般能用；个别 Snap 程序只认系统的输入法设置。
  • 密码框里念青五笔自动不工作（按键直接给程序）。
  • 置后词表（联想靠后词表）改了以后要重新启动输入法（ibus restart / fcitx5 -r）才生效；其余设置 2 秒内自动生效。
  • 出问题时可以把 nqwb-cli -v 按键 的输出和 ~/.config/nqwb/nqwb.conf 一起发给作者。

卸载

./install.sh --uninstall（全部），./install.sh --edition 86 --uninstall（只卸念青五笔，繁體用 --edition 86t）。或：sudo apt remove nqwb86 nqwb86t ibus-nqwb fcitx5-nqwb nqwb-common（Fedora 用 sudo dnf remove）。设置和自造词在 ~/.config/nqwb/，不会被删除。
