快捷键

念青五笔的全部快捷键与鼠标操作：输入、切换、造词、zz 临时拼音和软键盘。
更新日期 2026-11-14 · 适用于念青五笔 3.1.0.2611

快速上手快捷键设置说明码表说明已知问题字根与容错码关于与版本

输入

空格输出首选候选字词（用 ↑ ↓ 选过时输出选中的候选）。
1-9、0选择相应候选。
- =前后翻页（PgUp、PgDn 亦可）。
← →移动文档中的光标，已输入的编码保留，选字后输入在光标处。
↑ ↓在候选中上下移动选择，可跨页；联想词语亦同。
； '选择第二、第三个候选字词（须在设置中启用）。
1～8（空码时）选择猜测的词语，空格键输出第一个。
Backspace删除一位编码。
Esc取消输入。
Enter清空编码；在设置中勾选“Enter清空/英文上屏”后，输出编码字母。

切换

Ctrl+空格打开或关闭输入法（打开时恢复中文状态；Caps Lock 开启时除外）。
右 Shift切换中文 / 英文（须在设置中勾选“RShift切换中英状态”）。
Shift+空格切换全角 / 半角。
Ctrl+.切换中文标点 / 英文标点。
Ctrl+,切换简体 / 繁体输出。

词语

Ctrl+`开始 / 结束在线造词。
Ctrl+数字将该重码前移一位。

鼠标

单击“青 / A”切换中文 / 英文。
单击“念青五笔”约 0.5 秒后切换简体 / 繁体输出。
双击“念青五笔”当前窗口的输入法工具栏恢复自动停靠（同“恢复默认位置”）。
单击月亮图标切换全角 / 半角。
单击标点图标切换中文标点 / 英文标点。
单击键盘图标开启或关闭软键盘。
右键单击键盘图标选择软键盘布局。
右键单击工具栏打开主菜单（键盘图标除外）。
右键单击候选窗口打开主菜单（编码框亦同）。
任务栏“中 / 英”图标单击切换中文 / 英文，右键单击打开主菜单。
拖动工具栏移动输入法工具栏（仅限当前窗口，并随窗口移动）。
单击候选输出该候选。

zz 临时拼音

z z进入临时拼音（编码框显示“拼:”）。
空格 / 数字输出首选 / 选择候选字词。
- =前后翻页；↑ ↓ 移动选择；← → 移动文档中的光标。
Backspace删除一个拼音字母；字母删完后再按一次，退出临时拼音。
Enter / Esc输出拼音字母 / 取消。

软键盘开启时

字母、数字、标点键输入软键盘上的符号（Shift 键输入上排）。
其他键空格、Enter、Backspace、Esc 及方向键照常使用。
单击软键盘上的 Shift下一次单击输入上排符号。
单击软键盘上的 Caps锁定上排符号，再次单击解锁（仅限软键盘）。
单击 × 或键盘图标关闭软键盘，恢复五笔输入。
