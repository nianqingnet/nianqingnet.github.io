启用键盘（只做一次）

第一步：从 App Store 安装念青五笔。

第二步：打开 iPhone 或 iPad 的 设置 → 通用 → 键盘 → 键盘 → 添加新键盘…，在“第三方键盘”里选 念青五笔。

第三步：在任意输入框里按住键盘左下角的 地球键，选念青五笔即可开始打字。

日常打字不需要打开“允许完全访问”。只有在念青五笔 App 里导入自己的词库时，才需要临时打开，用来读取词库文件；导入完可以再关掉。

五笔输入，熟悉而顺手

  • 三套码表：86 版、98 版、新世纪五笔，在设置 → 码表中切换，自造词和词序按码表分开保存。
  • 经典打法：一级、二级、三级简码和全码，词语输入、逐键提示、编码提示；四码唯一自动上屏。
  • 万能键 z：拿不准的字根用 z 代替。
  • 空码猜词、重码补词：四码没有字词或候选很少时，按编码列出猜词作为补充，可在设置中关闭。
  • 智能调频（默认关闭）：常打的词越用越靠前。
  • 生僻字：码表收录部分扩展区用字，人名、地名也能打，可上屏、可简繁转换。
  • 自造词：边打边造，按当前码表规则自动算编码。

拼音辅助，五笔不掉线

  • 临时拼音：五笔状态下键入 zz 再打拼音，不用切换输入法；候选后面显示五笔编码，顺便学会打法。
  • 也可以在设置 → 码表里选“临时拼音”，直接全拼输入。

九宫格，单手也方便

  • 中文键盘可切换为九宫格，五笔、拼音都能打。
  • 左侧栏列出可能的编码或拼音，轻点选定。

自定义词库

在念青五笔 App 里可以导入自己的码表，支持 TXT 和 标准格式 MB 文件；TXT 认“词语 编码”“编码 词语”等常见写法。导入后可以给词库起名，在设置 → 码表里作为“一号词库”“二号词库”选用；内置码表里的词仍会用来补词、猜词。App 里带一份示例词库，可以先导入试试，试完在“码表”中切回 86 五笔或 98 五笔即可。

键盘皮肤

新增木棉、竹熊两套键盘皮肤，都有浅色和深色。英文模式、九宫格也会套用同一套皮肤，换外观时不用再单独调整。

  • 木棉：浅色、深色两套，键面点缀木棉花。
  • 竹熊：浅色、深色两套，竹子与熊猫元素落在键面上。

常见问题

  • 添加新键盘里找不到念青五笔：先打开一次念青五笔 App，再回到设置 → 通用 → 键盘 → 键盘 → 添加新键盘…。
  • 密码框里变成系统键盘：这是 iOS 的规定，密码框只能用系统键盘，第三方键盘都会自动换掉。
  • 导入词库失败：在设置 → 通用 → 键盘 → 键盘 → 念青五笔 里打开“允许完全访问”，导入完可以再关掉。
