在RHEL-AS4-U1里用minichinput

吴文官的怀旧文章：RHEL-AS4-U1 里有 minichinput，不过没有五笔输入法，不过没关系，还是想到了这个老版本的 minichinput（不过系统里原有的 minichinput 比这个还要老）。

吴文官：在RHEL-AS4-U1里用minichinput

在系统设置里有一个输入法转换程序，运行这个程序，将输入法切换为 minichinput，下载 minichinput-0.1.9，升级之：

$rpm -Uvh   miniChinput-0.1.9.i386.rpm

不需要修改 /usr/lib/Chinput/Chinput.ad 文件，但是要设置一下 locale。在 ~/.bashrc 文件中加入一行：

export LANG=zh_CN.GB2312

在 首选项 --> 更多首选项 --> 会话 中加入启动程序：chinput。这样每次进入 gnome 就可以自动运行输入法。如果是用 KDE，则可以加入到 ~/.kde/Autostart 中。

奇怪的问题：装好 miniChinput 后修改 /etc/X11/xinit/xinput.d/zh_CN 文件，将输入法设置为 chinput，登录后已经启动了 chinput，但是用 Ctrl+Space 却调不出来，所以只有通过其他方法实现它的自动运行。

外一篇：在RedHat Enterprise Linux4中为默认程序IIIMF添加五笔输入模块

作者：bin2　DEC10,2005

如果你觉得装 FCITX 太麻烦，也不美观，而且也不想删除系统自带的 IIIMF，那就照以下做吧，为 IIIMF 添加五笔输入模块。

1. 下载 miniChinput-0.1.9-2.i386.rpm：去 http://minichinput.sourceforge.net/
2. 解压：cat miniChinput-0.1.9-2.i386.rpm | rpm2cpio | pax -r
3. 将解压目录下 usr/lib/Chinput/im/cce/ 的 nqwb.tab 和 nqwb.tab.phr 复制到 /usr/lib/im/locale/zh_CN/chinput/cce
4. 将解压目录下 usr/lib/Chinput/im/ 下的 cce_hzinput.so 改名为 nqwb.so 并复制到 /usr/lib/im/locale/zh_CN/chinput
5. 编辑 /usr/lib/im/locale/zh_CN/chinput/Chinput.ad，系统默认五笔配置字段是注释掉的（字段前打了 !），先把 ! 全部去掉，再修改五笔那一段配置，将 FILE 字段改为：cce/nqwb.tab，MODULE 字段为 nqwb.so，其它不变如下：

[WB]
IMENAME         =       五笔字型
IMENAME         =       ^@<94>N^T{W[<8b>W
ENCODING        =       GB
FILE            =       cce/nqwb.tab
MODULE          =       nqwb.so
FAVORITE        =       YES

6. 重启 X，开始使用五笔吧！还可以切换智能拼音和五笔。
如果你只用智能拼音和五笔，还可以在 Chinput.ad 中把其它的输入法（如内码，双拼等）注释掉（在那一段每一行前都写一个“!”）
